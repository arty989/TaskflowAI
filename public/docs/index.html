Назначение проекта

TaskFlow AI — веб-приложение для совместного управления проектами и задачами. Пользователи создают Kanban-доски, добавляют задачи, меняют их состояние и приглашают других участников.

Функциональность

Аутентификация
Регистрация, вход, выход и восстановление сессии.
Доски
Создание, просмотр и настройка рабочих досок.
Задачи
Создание, описание, типы, исполнители и drag-and-drop.
Совместная работа
Приглашения, участники и уведомления.
Профиль
Имя, username, Telegram и аватар.
Локализация
Русский и английский интерфейс.

Архитектура и сетевое взаимодействие

Браузер
  │
  │ HTTPS
  ▼
Vercel: React + Vite
  │
  │ HTTPS-запросы к Supabase API
  ▼
Supabase
  ├── Authentication
  └── PostgreSQL + Row Level Security

Публичная версия доступна по HTTPS. Локально production-сборка запускается в Docker-контейнере: Nginx слушает порт 80 контейнера, который пробрасывается на порт 8080 компьютера.

Docker

cp .env.example .env
docker-compose up --build

После запуска приложение доступно по адресу http://localhost:8080, а проверка состояния — по адресу http://localhost:8080/health.

Технологии

React, TypeScript, Vite, Redux Toolkit, React Router, Supabase Auth, PostgreSQL, Docker, Nginx и Vercel.

Основной сценарий

  1. Пользователь регистрируется и входит в систему.
  2. Создаёт доску и добавляет задачи.
  3. Приглашает второго пользователя.
  4. Второй пользователь принимает приглашение.
  5. Оба участника работают с одной доской.
