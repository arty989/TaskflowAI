# Security Policy

## Reporting

Если вы обнаружили уязвимость, не публикуйте секреты в issue. Свяжитесь с владельцем репозитория напрямую.

## Secrets

В репозиторий запрещено добавлять:

- `.env` и `.env.local`;
- Supabase `service_role` и `sb_secret_...` ключи;
- Gemini/OpenAI и другие приватные API-ключи;
- пароли базы данных;
- приватные SSH-ключи.

Supabase publishable/anon key используется клиентским приложением и не предоставляет административный доступ. За разграничение доступа отвечают политики Row Level Security.
